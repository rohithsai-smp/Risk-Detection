Official Asset Exclusion Mechanism

Before any profile or mobile package triggers an alert, the system cross-references candidate handles, domains, and bundle IDs against the registered brand profile's authorized whitelist.

If a match is established, the candidate receives an automatic Risk Score of 0, marked as Safe / Whitelisted, preventing analyst alert fatigue and false positives.

Multi-Signal Explainability Formula

The risk scoring engine does not rely on opaque black-box models. It calculates an explainable weighted index:

Risk = (Fuzzy_Ratio × 0.35) + Substitution_Penalty + Keyword_Weight + Publisher_Discrepancy

Analysts can inspect exactly why a candidate received its score, empowering rapid defense actions.

Help & Documentation

User guide, scoring rubric, and API documentation for Digital Risk Shield.

Quick Start Guide

1. Start by navigating to Brand Profiles and registering your organization’s official properties (website, verified handles, developer name).

2. Use Social Monitoring and App Store Monitoring to review discovered threats. You can trigger simulated scans using the Trigger Scan button.

3. Use Name Risk Analyzer to interactively test candidate usernames or brand variations against RapidFuzz fuzzy algorithms.

4. Triage incidents in Threat Intelligence, add notes, and generate formal DMCA takedown letters.

Risk Score Rubric

  • 80–100 (Critical): Confirmed brand impersonation, high homoglyph evasion, direct credential phishing. Immediate takedown required.
  • 60–79 (High): Heavy lexical resemblance, appended deceptive terms (support, login, claim). Triage priority.
  • 30–59 (Medium): Partial similarity or fan discussion accounts. Ongoing passive monitoring.
  • 0–29 (Low): Coincidental lexical overlap. Minimal risk.
  • 0 (Safe): Verified brand asset matched on authorized whitelist.
